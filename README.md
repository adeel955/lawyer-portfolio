# Advocate Muhammad Ahmed - Portfolio Website

A professional, responsive lawyer portfolio website.

## 🚀 FREE Hosting on GitHub Pages (Step by Step)

### Step 1: Create a GitHub Account (Free)
1. Go to [github.com](https://github.com)
2. Click **Sign Up** and create a free account

### Step 2: Create a New Repository
1. Click the **+** icon (top right) → **New repository**
2. Name it: `lawyer-portfolio` (or anything you like)
3. Make sure it's set to **Public**
4. Click **Create repository**

### Step 3: Upload Your Website Files
1. On the repository page, click **uploading an existing file**
2. Drag and drop these files: `index.html`, `style.css`, `script.js`
3. Click **Commit changes**

### Step 4: Enable GitHub Pages
1. Go to your repository → **Settings** tab
2. Scroll down to **Pages** (left sidebar)
3. Under **Source**, select **main** branch
4. Click **Save**
5. Wait 1-2 minutes, then your website will be live at:
   **`https://YOUR-USERNAME.github.io/lawyer-portfolio/`**

## ✏️ How to Customize
- Open `index.html` in any text editor
- Replace **"Muhammad Ahmed"** with your friend's actual name
- Update phone number, email, address, and other details
- Replace placeholder photo with an actual photo
- Update practice areas, experience years, and testimonials
